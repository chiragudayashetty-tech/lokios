2. One "Today" screen: habits, tasks, protocols and Arena in a single scroll, ordered by what's due next.
3. Offline-first PWA: queue habit ticks/expenses when offline, sync later; real push notifications.
4. Clean up the dashboard (2,700 lines): break into components, remove dead widgets, faster load.
5. Settings page: edit penalties, 90% streak bar, daily budget, season dates, notification times.
